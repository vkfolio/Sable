# X (Twitter) launch

X is the lowest-information channel — short and visual. We use it for the "moment" and the thread for depth.

## Posting plan (launch day)

1. **6 AM PT** — post the launch tweet (`launch-tweet.md`). Pin it.
2. **6:01 AM PT** — quote-reply to it with the thread (`thread.md`). One quote-reply per tweet, one image per tweet where relevant. Don't auto-thread; reply manually so each gets indexed individually.
3. **8 AM PT** — DM 5-10 specific friends + builders who'd genuinely care. Don't blast.
4. **Throughout the day** — reply to *everything* from the launch tweet. X amplifies based on reply velocity.
5. **8 PM PT** — quote-tweet the launch tweet with one specific piece of feedback / a notable supporter. Show momentum.

## What works on X

- **Visual first.** The launch tweet has a video or hero image, not just text. Without a visual you'll get 1/10th the engagement.
- **One feature per tweet.** Each tweet in the thread shows one thing, with one image. Don't cram.
- **Don't end-rhyme the thread.** Last tweet has the link; the rest are pure show-and-tell.
- **Reply, don't lecture.** When someone asks a question, answer it directly without 3 paragraphs of qualifiers.
- **Quote-tweet kindly.** When supporters share, quote them with a thanks + a substantive add.

## What dies on X

- "Excited to announce…" — instant scroll-past.
- All-text tweets at launch. (Replies are fine to be all text.)
- Threads that are 20 tweets long. Cap at 10.
- Posting the same content as a 9-image carousel and a thread. Pick one.
- Begging for retweets ("RT please if you support open source"). Cringes the timeline.
