# Product Hunt — Sable launch

This folder is everything you'll paste into the PH listing form, plus a manifest of the visual assets we need.

## What's here

| File | Purpose |
| --- | --- |
| [`copy.md`](copy.md) | Title, tagline, description, topics, links — drop straight into the PH form |
| [`first-comment.md`](first-comment.md) | The maker's first comment, posted within 5 minutes of going live |
| [`assets/README.md`](assets/README.md) | Manifest of every gallery image / thumbnail / video we need |

## How a PH launch goes

1. **Schedule the listing** for 12:01 AM PT. You get a full PT day on the leaderboard.
2. **Maker comment goes up immediately.** The first comment from the maker(s) drives ~20% of votes — it's where people decide if they care. See `first-comment.md`.
3. **Reply to every comment** through the day. Vote velocity in the first 4 hours matters most.
4. **Don't ask people to vote.** PH penalises this hard. Share the link; let supporters self-organise.
5. **Don't fake hunters.** Submit it yourself, or have a real maker / friend do it.

## Asset specs (PH 2025)

- **Thumbnail / logo**: 240 × 240 px, PNG with transparency. Should read at small sizes — the icon, not a wordmark.
- **Gallery images**: 1270 × 760 recommended. 2-5 images. First image is the hero — it's what appears in the feed alongside the thumbnail.
- **Demo video**: optional but recommended. Max 60 seconds. 1280 × 720 minimum.
- **Topics / tags**: pick 3 from PH's list (see `copy.md`).

## What separates PH posts that work

- **The first image carries the post.** No screenshot? Post fails. Make it count.
- **Tagline reads as a complete thought.** Not a feature list — a feeling.
- **Maker comment opens with a story, not a feature list.** Why this exists is more interesting than what it does.
- **First-day responsiveness.** Reply within 30 minutes, every time. PH treats it as a signal.
