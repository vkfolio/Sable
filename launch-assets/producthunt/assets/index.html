Mixtral of Experts arxiv.org · 2401.04088

Mixtral of Experts

Albert Q. Jiang, Alexandre Sablayrolles, Antoine Roux, et al.

We introduce Mixtral 8×7B, a Sparse Mixture of Experts language model.

Even though each token only sees two experts, the selected experts can be different at each timestep. As a result, each token has access to 47B parameters but only uses 13B active parameters during inference.

Mixtral was trained with a context size of 32k tokens and outperforms Llama 2 70B and GPT-3.5.

What does "13B active" actually mean here?

Even though each token only sees two experts, the selected experts can be different at each timestep. Each token has access to 47B parameters but only uses 13B active parameters during inference. arxiv.org/abs/2401.04088 · §1
For every token at every layer, the router picks top-2 of 8 experts. Total parameter count stays 47B, but compute per token only uses ~13B — the unused experts are skipped.
Net effect: throughput close to a 13B dense model, capacity closer to 47B.
